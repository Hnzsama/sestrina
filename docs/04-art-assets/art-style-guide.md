# Panduan Gaya Visual (Art Style Guide)

- **Visual Style:** (2D Pixel Art / 3D Stylized Low Poly / Hand-drawn)

- **Accent Colors:** `#E94560`, `#0F3460`

## 3. Panduan Pencahayaan & Shading
