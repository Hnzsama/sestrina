# 02. Story & Lore
Folder ini digunakan untuk menyimpan dokumentasi alur cerita, karakter, dialogue script, dan latar dunia (world-building).

### File yang disarankan:
- `world-building.md`: Sejarah dunia, faksi, lokasi.
- `characters.md`: Bio karakter, motivasi, stat dasar, visual reference.
- `dialogue-scripts/`: File percakapan / quest log.
