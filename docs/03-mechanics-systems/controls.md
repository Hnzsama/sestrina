# 🎮 Control Scheme - Sestrina

## 1. Skema Kontrol Keyboard & Mouse (PC)

| Tombol / Input | Aksi | Keterangan |
| :--- | :--- | :--- |
| **W, A, S, D** | Pergerakan Pemain | Navigasi 8-arah (Vector movement) |
| **Spacebar / Shift** | Dodge Roll / Dash | Memberikan *Invincibility Frames (i-frames)* selama 0.3s |
| **Klik Kiri Mouse** | Light Attack | Serangan tebasan pedang cepat |
| **Klik Kanan Mouse** | Heavy / Special Attack | Serangan bertenaga dengan indikator cooldown |
| **E / F** | Interaksi | Mengambil *Lost Remedy* / Buka Pintu |
| **ESC / P** | Pause Game | Membuka Pause Menu |

## 2. Parameter Invincibility & Stamina Cooldown
- **Dodge Cooldown:** 1.0 detik setelah animasi Dodge selesai.
- **I-Frame Window:** Frame 3 hingga Frame 12 dari total 20 frame animasi Dodge.
