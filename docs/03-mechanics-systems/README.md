# 03. Mechanics & Systems
Folder ini digunakan untuk merinci sistem teknis dan aturan dalam game.

### File yang disarankan:
- `controls.md`: Skema input (Keyboard/Mouse, Gamepad, Touch).
- `combat-system.md`: Rumus damage, elemen, efek status.
- `progression.md`: XP curve, skill tree, reward system.
- `economy.md`: Harga item, currency, loot tables.
